optional movement basis, optional debug overlay. The existing movement helper has
only a two-line opt-in lookup; movement, climb and glide implementations were not
rewritten. The Cinemachine assembly references the already-installed Splines and
Mathematics assemblies. New materials, side-route geometry, tests and explicit
editor authoring utility were added. No package versions or global render settings
were changed. No new camera script uses ExecuteAlways, ExecuteInEditMode or
OnValidate. Third-party primitive components retain their existing behavior.
No automatic occlusion/fade, postprocessing, audio, menu, save or backend system
was added. Limitations and tuning trade-offs are documented in README.md.
Scene is saved and left open in Edit mode. Existing auto-tick and background
settings were already enabled and are retained.
